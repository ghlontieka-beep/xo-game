# XO თამაში (ონლაინ)

მარტივი ტიკ-ტაკ-ტო (XO) თამაში, სადაც ორ მოთამაშეს შეუძლია **სხვადასხვა კომპიუტერიდან** ერთმანეთს ეთამაშოს.

## როგორ ვითამაშოთ

1. ერთი მოთამაშე აჭერს **„ახალი თამაშის შექმნა"** — მიიღებს **კოდს**.
2. კოდს უზიარებს მეორე მოთამაშეს (მაგ. მესენჯერით).
3. მეორე მოთამაშე შეჰყავს კოდი და აჭერს **„თამაშში შესვლა"**.
4. კავშირის დამყარების შემდეგ ორივე ერთ დაფაზე თამაშობს რეალურ დროში.
   - შემქმნელი თამაშობს **X**-ით (პირველი სვლა), შემოსული — **O**-თი.

## ფუნქციები

- ონლაინ თამაში ორ კომპიუტერს შორის
- ქულების მრიცხველი (X / ფრე / O) — ინახება სესიის განმავლობაში
- გამარჯვების ხაზი — მოგებულ სამ უჯრაზე ანიმაციით გადაისმის

## ტექნოლოგიები

- HTML, CSS, JavaScript
- [PeerJS](https://peerjs.com/) (WebRTC) — მოთამაშეებს შორის პირდაპირი კავშირისთვის, საკუთარი სერვერის გარეშე

## ონლაინ გაშვება

იმისთვის, რომ ორმა ადამიანმა სხვადასხვა კომპიუტერიდან ითამაშოს, საიტი უნდა იდოს ჰოსტინგზე (მაგ. **GitHub Pages**), და ორივემ უნდა გახსნას **ერთი და იგივე მისამართი**.
