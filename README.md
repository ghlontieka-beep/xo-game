# XO თამაში (ონლაინ)

მარტივი ტიკ-ტაკ-ტო (XO) თამაში, სადაც ორ მოთამაშეს შეუძლია **სხვადასხვა კომპიუტერიდან** ერთმანეთს ეთამაშოს.

## როგორ ვითამაშოთ

1. ერთი მოთამაშე აჭერს **„ახალი თამაშის შექმნა"** — მიიღებს **კოდს**.
2. კოდს უზიარებს მეორე მოთამაშეს (მაგ. მესენჯერით).
3. მეორე მოთამაშე შეჰყავს კოდი და აჭერს **„თამაშში შესვლა"**.
4. კავშირის დამყარების შემდეგ ორივე ერთ დაფაზე თამაშობს რეალურ დროში.
   - შემქმნელი თამაშობს **X**-ით (პირველი სვლა), შემოსული — **O**-თი.

## ფუნქციები

- ონლაინ თამაში ორ კომპიუტერს შორის
- ქულების მრიცხველი (X / ფრე / O) — ინახება სესიის განმავლობაში
- გამარჯვების ხაზი — მოგებულ სამ უჯრაზე ანიმაციით გადაისმის
- სახალისო ფრაზა და საზეიმო ბგერა ყოველ მოგებაზე
- ერთ კომპიუტერზე თამაშის რეჟიმი — პარტნიორის გარეშე

## პირველი დაყენება (ერთხელ, ყოველ კომპიუტერზე)

```bash
git config core.hooksPath .githooks
```

ეს რთავს **push-ამდე ავტომატურ შემოწმებას**: ყოველი `git push`-ის წინ ლოკალურად
გაეშვება იგივე სინტაქსის ტესტი, რასაც CI აკეთებს. თუ კოდი გატეხილია — push ჩერდება
და გატეხილი კოდი GitHub-ს საერთოდ არ აღწევს.

გვერდის ავლა საჭიროებისას: `git push --no-verify`

## სამუშაო წესები

`main` დაცულია — პირდაპირ push შეუძლებელია. ყოველი ცვლილება Pull Request-ით შედის:

```bash
git switch -c ფუნქციის-სახელი    # ახალი ბრენჩი
# ... ვმუშაობ, ვტესტავ ...
git add . && git commit -m "რა გავაკეთე"
git push -u origin ფუნქციის-სახელი
gh pr create                      # ან GitHub-ის გვერდიდან
```

შესაერთებლად საჭიროა:

- ✅ `syntax-check` მწვანე (ავტომატური, ყოველ PR-ზე — ლოკალური hook-ის დუბლიორი)
- ✅ 1 დამტკიცება მეორე მონაწილისგან
- ✅ ბრენჩი განახლებული `main`-თან („Update branch" ღილაკი)
